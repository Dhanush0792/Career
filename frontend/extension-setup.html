04 // HOW AUTOFILL WORKS
DETECT
Extension detects the portal by URL pattern and picks the right fill engine
MAP
Scans form fields using CSS selectors or heuristic scoring against your profile data
PREVIEW
Shows you exactly what will be filled - field by field. You can modify any value before confirming
FILL
On your approval, values are typed into each field with proper React/Vue/Angular event triggers
YOU SUBMIT
The extension NEVER auto-submits. You review the filled form and click submit yourself

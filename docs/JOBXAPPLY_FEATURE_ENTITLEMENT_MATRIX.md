## 2. Misleading Terminology Audit

1. **"Unlimited" (`pricing.html:138, 141, 177, 201`)**: Server-side endpoints `/api/resume/generate`, `/api/cover-letter/generate`, `/api/ats/analyze`, and `/api/profile` enforce hard per-hour rate limits (`50/hr`, `30/hr`, `60/hr`) for abuse protection. Pricing copy should clarify *"Unlimited (subject to fair-use anti-abuse rate limits)"*.
2. **"Per month / Cancel anytime / Renews on" (`index.html:1984`, `pricing.html:135, 218`, `settings.html:529`)**: Directly contradicts `backend/plan-catalog.js:13` (`paymentType: "one_time_prepaid"`, 30 days, no auto-renewal).
3. **"Priority real-time sync" (`pricing.html:142`)**: No priority distinction exists in `sync-server.js` SSE or profile sync.
4. **"14-day job-found refund" (`pricing.html:225-226`)**: Advertised in Pricing FAQ, absent from `privacy-terms.html` and admin refund tooling.

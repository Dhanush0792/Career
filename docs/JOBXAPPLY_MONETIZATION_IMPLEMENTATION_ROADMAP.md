## 2. Phased Execution Plan (Minimum Viable Commercial Launch vs. Post-Launch)

- **Must Complete Before Launch (Minimum Viable Launch):**
  - **Phase A:** Finalize authoritative plan definitions (`GET /api/plans`) & fix billing/refund copy across `index.html`, `pricing.html`, `settings.html`, `privacy-terms.html`.
  - **Phase B & C:** Enforce Free vs. Pro boundaries (10/mo autofill quota, 20 tracker limit, enterprise ATS portal gating, cover letter/PDF alignment) + `user.emailVerified === true` fix (`MON-03`).
  - **Phase E (Minimal):** Render `payments[]` history table in `settings.html` (`MON-05`).
  - **Phase F (Minimal):** Add Admin Live-vs-Test Payments & Webhook Monitor (`MON-07`).
  - **Phase G & H:** Run simulated ₹199 Test Mode E2E on Render + Supabase, then switch to Live Mode (`rzp_live_*`, Live Webhook, `ENABLE_PUBLIC_CHECKOUT=true`) and verify one live ₹199 transaction.
- **Can Wait Until After Launch (P2/P3):**
  - Detailed funnel analytics charts (`MON-10`), background `chrome.alarms` polling (`MON-11`), inline recovery polish on `onboarding.html` (`MON-09`), automated Playwright browser suite.
